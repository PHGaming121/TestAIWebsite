TOKEN SAVER · INPUT CONTEXT ONLY

Compress what gets sent

Forge compresses the request copy of your conversation before it leaves the tab. Your prompt, your visible transcript and every file in your workspace stay exactly as they are.

Session totals

Savings are measured per request with Forge's own token estimator, so treat them as a close estimate rather than a provider-side invoice. Measured on the bundled samples: a 6-turn chat saves ~40%, a 12-turn agent session with commented files ~58–61%, and a 30-turn chat ~63–66%. Comment-heavy real projects save more; the lossless profile stays in the 15–30% range because it never rewrites wording.

CLAUDE MARKDOWN · LOADED AS MODEL DATA

Skills & project instructions

Anything Claude can read as markdown — CLAUDE.md, agents.md, SKILL.md, .claude/commands, .claude/agents — is discovered from the workspace, validated, and injected into the model context. Skills are progressive-disclosure: the model receives the index, then loads a full skill with read_skill when the task matches.

Skills loaded here live in this tab only. To keep one permanently, save the file into the workspace (for example .claude/skills/name/SKILL.md) and push it.
